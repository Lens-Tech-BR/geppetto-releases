# Geppetto — Instaladores Oficiais

Este repositório hospeda exclusivamente os instaladores públicos oficiais do aplicativo desktop **Geppetto** para macOS e Windows.

- **Página oficial de download:** [https://api.lenstech.com.br/download](https://api.lenstech.com.br/download)
- **Releases e assets:** Consulte a aba [Releases](../../releases) para obter as versões publicadas e seus respectivos arquivos de integridade (SHA-256).

> **Aviso:**
> - O código-fonte do Geppetto é proprietário e não é distribuído neste repositório.
> - O uso do aplicativo requer uma licença comercial válida.
